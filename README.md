# نظام طباعة الهويات — نسخة التطبيق

تطبيق ينصب على الآيفون والأندرويد بأيقونة خاصة، يفتح بملء الشاشة، ويشتغل بدون إنترنت.

## الملفات
```
index.html            التطبيق كامل
manifest.json         بيانات التطبيق (الاسم، الأيقونة، الألوان)
sw.js                 التشغيل بدون إنترنت
icon-192.png          أيقونة
icon-512.png          أيقونة
icon-maskable.png     أيقونة أندرويد الدائرية
apple-touch-icon.png  أيقونة الآيفون
```
كلها لازم تكون بنفس المجلد.

---

## النشر (مرة وحدة، مجاناً)

التطبيق يحتاج رابط https حتى ينصب. أسهل طريقة:

### GitHub Pages
1. سجّل بـ github.com واعمل Repository جديد باسم `id-print` واجعله Public.
2. اضغط **Add file ← Upload files** وارفع الملفات السبعة كلها.
3. **Settings ← Pages ← Source: Deploy from branch ← main ← / (root) ← Save**.
4. بعد دقيقتين يطلع رابطك:
   `https://اسم-حسابك.github.io/id-print/`

بدائل بنفس السهولة: Netlify Drop (اسحب المجلد وارفعه) أو أي استضافة عدك.

## التنصيب عند الزبون

**أندرويد** — يفتح الرابط بكروم، تطلع رسالة **تثبيت التطبيق**، أو من زر ⬇ تنصيب داخل التطبيق. تصير أيقونة بالشاشة الرئيسية مثل أي تطبيق.

**آيفون** — يفتح الرابط بسفاري (لازم سفاري، مو كروم)، يضغط زر المشاركة ⬆ ← **إضافة إلى الشاشة الرئيسية** ← إضافة. التطبيق داخل يعرض له هذا الشرح تلقائياً.

بعد التنصيب يشتغل بدون إنترنت نهائياً.

## محرر الصورة (قص وتعديل)
اضغط على أي صورة محمّلة داخل خانتها (زر "تم الوجه ✔") ويفتح المحرر:
- **قص**: مربع تسحبه من وسطه لتحريكه ومن زواياه لتغيير حجمه، مع شبكة إرشادية
- **▭ نسبة الهوية**: يقص تلقائياً بنفس نسبة القياس المحدد (٨.٦ × ٥.٦)
- **تدوير ٩٠°** و**قلب أفقي** — لصور السكنر المقلوبة
- سطوع وتباين لكل صورة على حدة
- **استبدال الصورة** من داخل المحرر

الأصل ينحفظ داخلياً، فتكدر ترجع تعدّل بدون فقدان جودة.
بنسخة الحاسبة: زر ✂ بجنب كل خانة.

## الطباعة

- **أندرويد**: زر طباعة مباشرة يفتح خدمة الطباعة — طابعة واي فاي أو USB أو حفظ PDF.
- **آيفون**: زر طباعة يولّد PDF بقياس A4 مضبوط ويفتح قائمة المشاركة، منها **طباعة** (AirPrint).

الـ PDF مضبوط على A4 بالضبط (595.28 × 841.89 نقطة)، يعني الهوية تطلع بقياسها الحقيقي بدون تصغير. المهم يختار الزبون ورقة A4 والمقياس ١٠٠٪.

## ملف APK للأندرويد (اختياري)

إذا تريد تبيعه كملف APK يرسله بالواتساب:
1. نصّب Android Studio على حاسبتك.
2. مشروع جديد ← Empty Views Activity.
3. حط ملفات التطبيق بمجلد `app/src/main/assets/`.
4. خلي الـ Activity تعرض WebView على `file:///android_asset/index.html` مع تفعيل JavaScript.
5. Build ← Generate Signed Bundle/APK.

أخبرني إذا تريد المشروع جاهز وأنطيك كل ملفاته.

**الآيفون ما يقبل هذا الأسلوب** — أي تطبيق آيفون يحتاج جهاز ماك وحساب مطوّر آبل بـ ٩٩ دولار سنوياً ونشر عبر App Store. لذلك طريقة "إضافة إلى الشاشة الرئيسية" هي الحل العملي للآيفون، والنتيجة عند الزبون نفس الشي: أيقونة وتطبيق بملء الشاشة.
